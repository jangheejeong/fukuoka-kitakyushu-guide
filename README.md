# 후쿠오카 · 기타큐슈 여행 가이드

배포 저장소: `jangheejeong/fukuoka-kitakyushu-guide`  
공개 주소: https://jangheejeong.github.io/fukuoka-kitakyushu-guide/

## 계획 기준

헤르메스 여행 세션의 항공 예약 화면과 숙소 메시지, 후속 숙박 예약 화면을 참고했습니다.

- 10/8: 국제선 도착 13:40. 입국·수하물 여유 90분을 둡니다.
- 10/9: 가족 국제선 도착 18:30. 입국·수하물 여유 75분을 둡니다. 하카타 숙소 체크인 마감은 22:00입니다.
- GRAND BASE Hakata Gofuku: 10/8~10/10. 체크인 15:00부터, 체크아웃 10:00까지.
- 이타쿠라 KF1: 10/10~10/12. 체크인 16:00부터, 체크아웃 11:00 전. 13:00 이후 입구 짐 보관은 호스트 안내 기준이며 재확인이 필요합니다. 체크아웃 후 짐 보관은 불가합니다.
- KF1 위치는 구즈하 2초메 8 일대의 근사 핀입니다. 실제 건물 위치는 호스트 안내로 확인합니다.
- 10/12: 국제선 출발 18:00. 공항 도착 목표는 15:00입니다.
- 렌터카는 견적 단계로, 확정 예약으로 취급하지 않습니다.

공개 페이지에는 예약번호, 출입 비밀번호, 사전 체크인 링크를 넣지 않습니다. 기존 공개본에서 제외한 항공편 번호와 일행 인원도 유지합니다.

## 추천 중심 화면의 인수 기준

1. 첫 화면은 날짜별 추천 코스 2~3개를 제시합니다. 출발지·도착지 직접 입력은 부가 기능으로 둡니다.
2. 공항 도착·입국·숙소 이동·체크인·체크아웃·지역 간 이동·귀국 공항 도착을 기본 일정에 포함합니다.
3. 10/8 관광은 숙소 체크인 및 짐 정리 뒤에 시작하며, 숙소를 건너뛰는 코스를 제시하지 않습니다.
4. 각 코스에는 추천 이유, 관광 순서, 해당 동선의 식사 기본안과 대안, 시간표가 있습니다.
5. 자연·작은 동네·부모님 및 아기 동반 여유를 고려한 기본 추천과 비·피로 상황의 대안을 제시합니다.
6. 코스와 식당을 바꾸면 고정 구간을 유지하면서 전체 타임라인을 갱신합니다.
7. 계산에는 각 이동·체류·휴식 시간이 포함되며, 체크인 및 공항 마감과 충돌하는 대안은 선택할 수 없습니다.
8. 날짜마다 선택을 따로 저장합니다. 잘못된 저장 값이나 저장 불가 환경에서도 기본 추천이 동작합니다.
9. 이동·운영·식사 시간은 계획용 추정입니다. 늦은 가족 도착일 식사는 체크인 후 영업 확인이 필요한 조건부 선택으로 명시합니다.
10. 기존 관광지 사진·식당 상세·직접 동선 계산 기능을 계속 열 수 있습니다.

## 배포

현재 GitHub Pages는 `main` 브랜치 루트를 게시합니다. GitHub가 생성한 `pages-build-deployment` Actions 워크플로가 커밋 이후 빌드·배포합니다. 별도 호스팅이나 다른 GitHub 계정을 사용하지 않습니다.

```sh
gh auth status
git remote -v
```

활성 계정과 원격 저장소의 소유자가 모두 `jangheejeong`인지 확인한 뒤 검증된 변경을 푸시합니다. 배포 결과는 저장소 Actions와 실제 공개 페이지에서 확인합니다.

## 로컬 검증

```sh
node --test tests/*.test.mjs
python3 -m http.server 8766 --bind 127.0.0.1
```

브라우저에서 `http://127.0.0.1:8766/`을 엽니다. 프레임워크 설치 없이 ES modules로 동작합니다. `.nojekyll`로 정적 파일을 그대로 게시합니다. `planner/data.mjs`에 장소·계획 시간 범위·지역을, `planner/engine.mjs`에 이동 시간과 마감 계산을 둡니다.

Google Maps 링크는 실제 교통 확인을 위한 것입니다. 이 앱이 실시간 지도 API를 호출하거나 현재 영업을 확인하지는 않습니다. 같은 지역의 식사 후보와 지역 간 보수적인 이동 시간을 바탕으로 계획합니다.

## 추천 근거

2026-10-07에 공식 안내, 실제 Google Maps 평점·노출 후기, 여행 커뮤니티 방문기를 비교했습니다. 공식 사실, 확인한 후기 표본, 추천자의 판단을 구분합니다. 노출 후기 표본은 전체 리뷰의 합의를 뜻하지 않습니다. 미조사 식당·시설은 조건 확인용 대안으로 표시합니다. 단체 빈자리와 예약 가능 여부는 확정하지 않았으며, 대기 시간은 계획용 가정입니다. 가족 식사는 단체 좌석·예약·유모차 접근·아기띠 보조와 대기 여유를 고려합니다.

추천 화면은 index.html과 itinerary.html이며, planner/scenarios.mjs가 고정 일정과 추천 코스를 계산합니다. manual.html은 직접 동선 계산 화면입니다.
